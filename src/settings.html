✨ Live remarks generated by Muse (wake method)

While idle (IDLE), Muse generates a batch of short one-liners (mascot-quotes) in the background, which are shown first as the mascot's own words. When the pool is empty, it automatically falls back to the fixed lines below (quotes.json).

⚠️ Note: Each wake uses 1 turn of Muse's usage limit (Usage Limit). If you select "Main chat", the wake request and reply remain in the chat history.
